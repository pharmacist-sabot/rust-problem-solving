## วิธีมีส่วนร่วม (How to Contribute)

เรายินดีต้อนรับการมีส่วนร่วมจากทุกคน! ไม่ว่าจะเป็น:

### 📝 เนื้อหา (Content)
- เขียนบทความใหม่เกี่ยวกับปัญหาที่พบใน Rust
- ปรับปรุงคำอธิบายหรือตัวอย่างโค้ดที่มีอยู่
- แปลเนื้อหาเป็นภาษาอื่น

### 🐛 แจ้งปัญหา (Bug Reports)
- พบข้อผิดพลาดในเนื้อหา? เปิด [Issue](https://github.com/pharmacist-sabot/rust-problem-solving/issues) ได้เลย
- แจ้ง Typo, ลิงก์เสีย หรือโค้ดตัวอย่างที่ไม่ถูกต้อง

### 💡 เสนอหัวข้อใหม่ (Feature Requests)
- มีปัญหา Rust ที่น่าสนใจ? เสนอเป็นหัวข้อบทความใหม่ได้
- แนะนำการปรับปรุงโครงสร้างหรือ UX ของหนังสือ

### ขั้นตอนการ Contribute

1. **Fork** Repository จาก [GitHub](https://github.com/pharmacist-sabot/rust-problem-solving)
2. สร้าง **Branch** ใหม่สำหรับการแก้ไข
3. เขียนเนื้อหาหรือแก้ไขตามต้องการ
4. ทดสอบด้วย `mdbook build` ให้แน่ใจว่า Build ผ่าน
5. เปิด **Pull Request** พร้อมคำอธิบายสิ่งที่เปลี่ยนแปลง
